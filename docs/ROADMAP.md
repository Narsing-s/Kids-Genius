# Implementation roadmap

## Phase 1 — Foundation
- [x] Monorepo structure for web, Android and shared learning content
- [x] Bilingual age bands and subject catalogue
- [x] Initial sample questions
- [x] Supabase schema and parent-scoped RLS baseline
- [ ] Install dependencies and validate web/mobile builds

## Phase 2 — Core learning
- [ ] Parent sign-up, sign-in and consent workflow
- [ ] Parent-created child profiles and age-band selection
- [ ] Quiz engine with picture, multiple-choice, matching and audio activities
- [ ] English/Telugu language toggle and reviewed translations
- [ ] Accessible audio narration and pronunciation

## Phase 3 — Motivation and reporting
- [ ] Stars, badges, milestones and printable certificates
- [ ] Subject-wise progress and learning history
- [ ] Parent dashboard and daily screen-time settings
- [ ] Offline-friendly lesson caching

## Phase 4 — Release
- [ ] Content review and age-appropriateness testing
- [ ] Security/RLS testing, privacy review and deletion/export flows
- [ ] Web deployment and Android APK/AAB build
- [ ] Accessibility, device and performance testing
